PokeDeck

プライバシーポリシー

制定日 2025年1月18日 ／ 最終更新日 2026年9月5日

このページは、ポケモンカードのデッキ管理アプリ PokeDeck（Android 版・iPhone 版）と、 このウェブサイトでの情報の扱いについて説明するものです。両方に同じ内容が当てはまります。

先に、いちばん大事なところだけ。

  • ログインしなくても、ほとんどの機能はそのまま使えます。
  • ログインした場合だけ、マイデッキなどをクラウドに預かります。
  • 預けたものは、アプリの「設定 → アカウントを削除」でいつでもご自身で消せます。
  • デッキの名前や中身を、利用状況の記録として送ることはありません。

1. 集める情報

アカウントの情報（Google でログインしたときだけ）

メールアドレス、表示名、プロフィール画像、アカウントを見分けるための ID を、 Google から受け取って保持します。ログインしなければ、これらは一切受け取りません。

クラウドに預かるデータ（Google でログインしたときだけ）

マイデッキ、対戦記録、大会の予定を、上記のアカウント ID と結びつけて保存します。 別の端末で同じ内容を使えるようにするため、および機種変更のときに引き継げるようにするためです。

利用状況（Firebase Analytics）

アプリがどこで使われ、どこで止まっているかを知るために、次のものを記録します。

  • 画面の遷移と、共有・取り込みなど操作の種類と回数
  • 端末の種類、OS の版、言語、地域
  • アプリのインストールごとに割り当てられる識別子
  • IP アドレスから推定されるおおまかな地域（市区町村より粗い単位）

デッキの名前・中身・カードの種類は、ここには含めていません。 記録しているのは「共有を作った」「取り込んだ」といった操作の種類と、その枚数などの数だけです。 誰がどんなデッキを組んだかは、こちらが知る必要のない情報だと考えています。

広告（Google AdMob）

アプリには広告が表示されます。広告の配信と効果測定のために、 Google およびその提携先が広告用の識別子などを利用することがあります。 これは他社のアプリやウェブサイトをまたいだ追跡に使われる場合があります。 iPhone では、この追跡を許可するかどうかを OS の設定でご自身で選べます。

通知（Firebase Cloud Messaging）

お知らせを届けるために、端末ごとの通知用トークンを保持します。 通知を許可しなければ使いません。

このウェブサイト

Cloudflare Web Analytics を使って、ページの閲覧数と参照元を数えています。 Cookie を置かず、個々の訪問者を追いません。 共有リンクのページも同じ扱いです。

2. 使う目的

  • アプリとサービスの提供・運営
  • クラウド同期（ログインした場合）
  • 不具合の把握と、使われ方に基づく改善
  • 広告の表示
  • お問い合わせへの対応
  • 利用規約に反する行為の調査

これ以外の目的には使いません。集めた情報を販売することもありません。

3. 第三者への提供

次の場合を除いて、集めた情報を第三者に提供することはありません。

  • ご本人の同意があるとき
  • 法令に基づくとき
  • 人の生命・身体・財産を守るために必要なとき

なお、上記の機能を動かすために Google（Firebase・AdMob） と Cloudflare のサービスを利用しており、それぞれの取り扱いは各社の プライバシーポリシーに従います。

4. 共有リンクについて

デッキを共有すると /d/?c=… という形のリンクができます。 デッキの中身はリンクの文字列そのものに入っていて、こちらのサーバーには保存していません。 誰がどのデッキを共有したかの記録も残していません。

そのかわり、一度配ったリンクは取り消せません。 リンクを知っている人は誰でもその中身を見られます。共有する相手にはご注意ください。

5. 保存する期間と、消し方

クラウドに預かったデータは、アカウントが存在する間ずっと保持します。 アプリの「設定 → アカウントを削除」から、いつでもご自身で削除できます。 アカウントと、クラウド上のマイデッキ・対戦記録・予定がまとめて消えます。

アプリをすでに削除しているなどでこの操作ができない場合は、下のお問い合わせ先へご連絡ください。 こちらで削除します。

端末の中だけに保存されているデータ（クラウド同期していないデッキなど）は、この操作の対象外です。 アプリをアンインストールすると消えます。

利用状況の記録は、Firebase Analytics の設定に従って一定期間で自動的に消えます。 個人を特定できる形では保持していません。

6. 情報の管理

情報の漏えい・紛失・改ざんを防ぐため、適切な安全管理の措置をとります。 クラウドに預かったデータは、ログインしたご本人以外が読めない設定にしています。

7. 情報の開示・訂正・削除

ご自身の情報の開示・訂正・削除を求めることができます。 ご連絡をいただき次第、速やかに対応します。

必要に応じて内容を変更することがあります。変更したときは、このページの最終更新日を改めます。 大きな変更のときは、アプリ上でもお知らせします。
