FEATURES

アプリでできること

MY DECKS

デッキを、 ひと目で。

タイプ色の帯とドット絵で見分ける。 長押しで並べ替え、Google ログインで 別の端末とも同じ内容に。

EVENT RESULTS

大会の入賞デッキを、 毎日。

シティリーグの結果を日付ごとに。 優勝から入賞まで、代表カードと ドット絵で一覧できます。

TOURNAMENT

入賞デッキを、 そのままコピー。

気になるデッキの60枚を眺めて、 「マイデッキにコピー」を1回。

CARD SEARCH

8,000枚以上から、 ひらがなのままでも。

打っている途中でも候補が出ます。 関連カードや再録も一緒に。

FILTER

タイプや進化で、 すぐ絞れる。

押した瞬間に件数が変わるので、 開き直さずに条件を決められます。

DECK EDIT

タップで枚数、 その場で保存。

60枚の進捗を見ながら組み立て。 吹き出しで増減・詳細・外すまで。

SAVE AS IMAGE

デッキを、 1枚の画像に。

ドット絵を添えて書き出し。 SNSでの共有に。

DECK CODE

デッキコードを、送れるリンクに。

公式のデッキコードを貼るだけ。アプリが無くても、この画面で作れます。 受け取った人はアプリを入れていなくても中身が見えて、入れていれば1回で自分のデッキになります。

開いてみる

デッキの中身はリンクそのものに入っています。こちらには何も保存していません。 そのぶん、一度配ったリンクは取り消せません。
